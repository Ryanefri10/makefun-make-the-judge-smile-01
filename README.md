One line, at most 200 characters, about a small good thing that happened today — something that would make a reader smile. This program writes that line to `/output/entry.txt`.

The line: *At 5 a.m. the satay man slipped an extra skewer into my hand and whispered, 'on the house — the rain already paid me in customers.'*

## Run it

```sh
python3 main.py
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
